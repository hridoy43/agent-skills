# GitHub README and Profile Writing

Create SEO-friendly, conversion-aware READMEs for GitHub projects, skills, organizations, and personal profiles.

## Install

```bash
npx skills@latest add hridoy43/agent-skills \
  --skill github-readme-and-profile-writing \
  --global
```

## Use it

Invoke `$github-readme-and-profile-writing` and provide the repository or profile path, audience, project status, canonical links, approved claims, and desired action.

The skill interviews before writing, keeps important content textual and discoverable, and separates product users, contributors, clients, and networking audiences. It supports project, skill, organization, and profile README templates, with optional service and ethical affiliate sections.
