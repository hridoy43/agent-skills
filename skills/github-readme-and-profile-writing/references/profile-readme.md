# Personal profile README

1. Positioning headline: role, domain, outcome.
2. Short intro: who they help and what they build.
3. Focused links: portfolio, professional profile, contact, chosen social channels.
4. Selected work with honest status labels: current products, open source, shipped outcomes.
5. Credibility only when approved: past companies, clients, talks, writing, measurable results.
6. Capabilities: a concise focus or stack summary, never a dependency dump.
7. One clear path to hire, collaborate, follow, or give feedback.

Keep owned products, past work, services, and community projects visibly separate. Prefer a few strong examples to exhaustive lists. Use the person's own voice and specific claims. Make services specific and evidence-led, not an agency brochure. Plain links and selected work usually beat badges on profiles.
